# Lens (lasso-search) Implementation Plan

> **For agentic workers:** the user ruled out the builder skills for this work. Implement inline, task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Circle any part of the screen or an image file, then get its text or send it to Google Lens, from a `lasso` command and a `/lens` skill.

**Architecture:** Rebuild the kremit/lasso-search fork as a small Python package. One input step (capture the screen or open a file) feeds one overlay, and the result goes to one action (`scan` or `search`). Capture, clipboard and upload sit behind platform and provider seams, so Mac and Windows only add backends in the next phase.

**Tech Stack:** Python 3.10+, tkinter (stdlib), Pillow, `tesseract` and `zbarimg` as optional binaries, `unittest`.

**Spec:** this file. Decisions come from the 2026-11-07 session:
- Cross-platform through standard Python. X11 and Wayland ship first, Mac and Windows are the next phase.
- No AI in this tool. `scan` means circle to text. Squigit's ask, context and search features go to `doc/TODO.md`.
- Input is the first step of both actions, so there is no `--print-path` flag. The crop path is part of the JSON result.

## Global Constraints

- Repo: clone `git@github.com:kremit/lasso-search.git` to `~/dev/projects/lasso-search`. Work on `main` there, MIT license stays.
- Runtime dependencies: Pillow only. No GTK, no pytesseract, no numpy. Call binaries with `subprocess.run` and argument lists, never a shell.
- Commands: `lasso scan [IMAGE] [--monitor N] [--lang eng] [--no-copy]` and `lasso search [IMAGE] [--monitor N] [--upload]`.
- `lasso` prints one JSON object on stdout: `{action, source, image, selection, text, confidence, codes, copied, host_url, lens_url, expires_at, error}`.
- Exit codes: 0 ok, 2 cancelled, 3 no text found, 4 missing tool, 5 error, 64 usage.
- Crops go to `~/.cache/lasso-search/` (`XDG_CACHE_HOME` respected) with mode 0600. Delete crops older than 24 hours on each run.
- Nothing leaves the machine unless `--upload` is passed. `search` without it copies the crop to the clipboard and opens `https://lens.google.com/` for a manual paste.
- Python: 4-space indent. Comments short.
- Commits use a plain message plus `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do not push without asking.

## Verified Facts

- This box: Pillow `ImageGrab` has XCB, grabs 3840x1200 across both monitors in 47 ms, and takes a `bbox`. Tk 9.0.2 and `ImageTk` load on Python 3.14. So X11 needs no `maim`.
- Monitors: DP-0 1920x1200+0+0 and DP-2 1920x1200+1920+0, read from `xrandr --listmonitors`.
- `tesseract IMAGE stdout tsv` output columns: `level page_num block_num par_num line_num word_num left top width height conf text`.
- imagepaste.org publishes no API. Its own page sends `POST /api/upload` with the raw image as the body and the MIME type as `content-type`, and reads `url` and `key` from the JSON reply. Anonymous links last a fixed 7 days at 20 uploads per day, 20 MB, JPEG, PNG, GIF or WebP.
- No expiry option appears in the site's client code, so a 1 hour expiry is **unconfirmed**. Task 6 checks this before relying on it.
- Task 6 result, 2026-11-07: the reply has `imageUrl`, a raw `image/png`, and `expiresAt`. `expires`, `ttl`, `expiry` and an `x-expires` header were all ignored, so links last 7 days. Lens accepts the URL: its redirect carried `vsdim=607,278`, the test image's size.

## Review Focus

- A selection on the second monitor must crop that monitor, not an offset area of the first. Task 2.
- A display scale above 1 means the overlay and image sizes differ, and the crop must still match what was circled. Task 2.
- Escape, a right click, or a selection under 8 px must cancel cleanly, leaving no file and exiting 2. Task 3.
- With `tesseract` missing, `scan` exits 4 and names the install step instead of a traceback. Task 4.
- A failed upload, including a 429 daily limit, must fall back to the manual Lens flow and report why. Task 6.
